================================================================================
                            DATA FLOW DIAGRAM
================================================================================

STUDENT LOGIN FLOW:
  Browser → Login Form → Supabase Auth → Dashboard → Display Content

ADMIN CREATE EVENT FLOW:
  Admin Form → API Route → Supabase DB → Real-time Update → Student Dashboard

CONTENT WITH LINKS FLOW:
  Admin adds text with URL → Stored in DB → Component renders → TextWithLinks
  → Detects URL → Makes it clickable → User clicks → Opens in new tab

OAUTH FLOW:
  User clicks "Google/GitHub" → Provider page → Approval → Callback route
  → Role selection → Metadata update → Dashboard access
