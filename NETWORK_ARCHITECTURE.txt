================================================================================
                       API ENDPOINT ARCHITECTURE
================================================================================

ANNOUNCEMENT API:
  POST   /api/announcements          → Create
  PUT    /api/announcements/[id]     → Update (async params)
  DELETE /api/announcements/[id]     → Delete (async params)

NOTICE API:
  POST   /api/notices                → Create
  PUT    /api/notices/[id]           → Update (async params)
  DELETE /api/notices/[id]           → Delete (async params)

EVENT API:
  POST   /api/events                 → Create
  PUT    /api/events/[id]            → Update (async params)
  DELETE /api/events/[id]            → Delete (async params)

MATERIAL API:
  POST   /api/materials              → Upload file
  DELETE /api/materials/[id]         → Delete (async params)

AUTH API:
  POST   /api/auth/callback          → OAuth redirect handler

All endpoints include:
✓ Authentication check
✓ Role-based authorization
✓ Error handling
✓ Input validation
✓ Async parameter handling (Next.js 16)
