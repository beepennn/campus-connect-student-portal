│                                                                           │
│  GET    /api/events            ← List events                            │

│  DELETE /api/events/[id]       ← Delete (admin)                         │

┌─ TROUBLESHOOTING ─────────────────────────────────────────────────────────┐

│                                                                           │
│  Can't see admin panel?                                                  │
│  → Make sure you signed up as "Faculty/Admin"                          │

│  → Check browser console for errors                                     │
