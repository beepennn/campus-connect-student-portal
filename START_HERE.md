## 🚀 Quick Start (3 Steps)

### Step 1: Run Locally
```bash
npm install
npm run dev
# Visit http://localhost:3000
```

### Step 2: Test It
- Create admin account (select "Faculty/Admin" during signup)
- Create student account
- Admin: Create notice → See it on student dashboard
- Admin: Upload material with file → Student downloads it
- Check mobile responsiveness

### Step 3: Deploy
```bash
git push  # GitHub → Vercel auto-deploys
```

**Done! Your app is live on the internet!**
